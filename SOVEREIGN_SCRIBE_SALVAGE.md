## 1. Clinical IP — DSM-5-TR <-> ICD-11 billing crosswalk (unique)
A JSON matrix the pipeline checks before finalizing the Assessment, so the local
LLM can't hallucinate codes/specifiers. Source: `DSM_ICD11_TRANSLATION_V11`.

```json
{"diagnostic_crosswalk": [
  {"dsm_5_tr_diagnosis": "Major Depressive Disorder, Single Episode, Moderate",
   "icd_11_code": "6A70.1",
   "required_specifiers": ["severity: moderate", "course: single episode"],
   "clinical_threshold": ">=5 symptoms in the same 2-week period",
   "billable_status": true},
  {"dsm_5_tr_diagnosis": "Generalized Anxiety Disorder",
   "icd_11_code": "6B00",
   "required_specifiers": ["duration: minimum 6 months"],
   "clinical_threshold": "Excessive anxiety/worry more days than not",
   "billable_status": true},
  {"dsm_5_tr_diagnosis": "Adjustment Disorder with Depressed Mood",
   "icd_11_code": "6B43.0",
   "required_specifiers": ["onset: within 3 months of stressor"],
   "clinical_threshold": "Emotional/behavioral symptoms in response to an identifiable stressor",
   "billable_status": true}
]}
```
**Gate logic:** AI diagnosis must exactly match a `dsm_5_tr_diagnosis` string and
append the matching `icd_11_code`; on mismatch, n8n routes the draft to a
"Flagged for Human Review" queue instead of finalizing. Guardrail name:
`HALLUCINATION_ZERO_DIAGNOSTICS`. (Extend with more dx as needed.)

## 2. Tennessee compliance guardrails (unique — would have to re-research)
Source: `SUPPLEMENTAL_TACTICAL_V3`.
- **TN SB 1580** (eff. 2026-07-01): AI may not pose as a healthcare professional ->
  **Mitigation:** strict "Scribe-Only" role + mandatory "Final Sign-off" disclaimer.
- **TN HB 1455:** restricts AI-simulated relationships -> **Mitigation:**
  "Terminal Medical" logic — strip all empathetic/supportive language.
- **ELVIS Act:** protects voice/likeness -> no voice cloning / biometric sim.
- **Jackson zoning:** home occupation <=500 sq ft; Minimal Activity License
  ($15) due at $3,000 gross.
- **Security:** CVE-2026-33660 (n8n SQL-merge RCE) -> patch to n8n v2.14.1.
  Air-gap mesh (zero-WAN) for demos; ePHI never crosses WAN; AES-256 at rest.

## 3. The "Cold Scribe" master prompt (workflow)
Source: `MASTER_ASSET_VAULT_V4`. Engineered to satisfy SB 1580 + HB 1455.
```
Role: Clinical Documentation Utility (Non-Social).
C1: Output only professional, medical-terminal SOAP narrative.
C2: Prohibited from empathetic/supportive/conversational language
    (no "I'm sorry to hear", "that sounds difficult").
C3: "Red Thread" — every clinical observation explicitly linked to a quote or
    observable behavior in the transcript.
C4: Mandatory footer: "Draft generated by Sovereign Scribe Utility.
    Final clinical validation by [Practitioner Name]."
INPUT: {{ $json.sanitized_transcript }}   OUTPUT: SOAP [S,O,A,P]
```

## 5. Empirical hardware tuning (unique — learned the hard way)
Source: `MASTER_ASSET_VAULT_V4` + `STRESS_TEST_M1_RECALIBRATION_V12`.
- MacBook 16GB -> **9.6GB UMA target**. LM Studio: load to VRAM only, Flash
  Attention ON, **KV cache 4-bit**.
- Context 16,384 tokens (tuned for 30-45 min sessions inside the 9.6GB buffer).
- GPU offload max, 4 threads; **prune n8n execution data every 24h** (Node.js
  memory bloat). Known failure: hang at transcript #42 -> fixed via n8n guardrails.

- **Substantial Human Modification audit schema** (`PILOT_READY_TACTICAL_V13`):

- **5-cycle audit** (`RESEARCH_HARDENING_V19`): standardize dx (ICD-11) -> verify
